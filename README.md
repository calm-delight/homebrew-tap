# Calm Delight Homebrew tap

```bash
brew install --cask calm-delight/tap/agentduck
```

| Cask | App |
|---|---|
| `agentduck` | [AgentDuck](https://getagentduck.com) — tokens, cost and plan limits for Claude Code, Codex, Grok and Cursor in the macOS menu bar. Apple silicon, macOS 14 or later. |

AgentDuck updates itself through Sparkle (`auto_updates true`), so `brew upgrade` only matters for fresh installs.
